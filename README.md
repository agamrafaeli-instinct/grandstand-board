# Grandstand board

A Grandstand instance that watches the Grandstand project board (https://github.com/users/agamrafaeli-instinct/projects/2).
The tool lives in https://github.com/agamrafaeli-instinct/grandstand. This repo holds only the config (`board.config.json`) and the workflow that bakes the board and deploys Pages. Live: https://agamrafaeli-instinct.github.io/grandstand-board/
